# PNG2PDF-by-Jair-Lima

## Descrição
Converte imagens em PDFs pesquisáveis com OCR, filtrando pelo texto encontrado nas imagens.

## Stack
Python 3, Tesseract OCR, pytesseract, Pillow.

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python png2pdf.py termo`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
